This page maps out a static frontend + serverless API architecture on AWS. It's hosted here on GitHub Pages for now — the AWS pieces (S3, CloudFront, Lambda, API Gateway, DynamoDB) come next, once the design is settled.

The architecture

A static site served from S3 through CloudFront, with a separate serverless API path for anything dynamic.

How a request flows

Two paths: one serves the page, the other serves data.

01

Browser requests the site

CloudFront caches and serves the static files (HTML, CSS, JS) that live in the S3 bucket, over HTTPS with a CDN edge close to the visitor.

02

Page loads, calls the API

Client-side JS calls an endpoint exposed by API Gateway — the same S3/CloudFront path never touches application logic directly.

03

Gateway triggers a Lambda function

API Gateway routes the request to a Lambda function, which runs only for the duration of that request — no server to keep running or patch.

04

Lambda reads or writes DynamoDB

The function talks to a DynamoDB table for anything that needs to persist, then returns a response back up the same chain.

The stack

Every piece here is pay-per-use — nothing runs (or costs anything) while idle.

STORAGE
S3
Hosts the built static files.
DELIVERY
CloudFront
CDN, caching, HTTPS at the edge.
API
API Gateway
Routes and throttles requests.
COMPUTE
Lambda
Runs the backend logic on demand.
DATA
DynamoDB
Key-value store for app data.

Deploy plan

Where this project is now, and what moving it to AWS actually involves.

NOW

Static site on GitHub Pages. This page, hosted for free, no AWS account needed yet — good for sharing the idea and iterating on design.

NEXT

Move hosting to S3 + CloudFront. Upload the same files to an S3 bucket, put CloudFront in front of it, attach a custom domain if wanted.

NEXT

Add the API layer. Write one small Lambda function, wire it to API Gateway, and give it a DynamoDB table for whatever needs to persist.

LATER

Automate it. A GitHub Actions workflow that deploys straight to AWS on every push, instead of uploading by hand.
